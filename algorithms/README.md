# Algorithms

| Algorithm | Primary data | Common uses |
|---|---|---|
| ANN | Tabular/vector | Classification, regression |
| Sigmoid | Scalar/vector | Binary probability output and gating |
| CNN | Images/spatial signals | Vision, spatial feature extraction |
| RNN | Sequential | Time series, sequences |
| LSTM | Sequential | Long-range temporal dependencies |
| GRU | Sequential | Temporal modeling with fewer gates than LSTM |
| LSM | Event streams/sequences | Spiking and neuromorphic computing |
| RBF Network | Vector/tabular | Classification and function approximation |
| SAE | Vector/tabular | Sparse feature learning |
| VAE | Vector/image | Probabilistic representation and generation |
| GAN | Images/other data | Generative modeling |
